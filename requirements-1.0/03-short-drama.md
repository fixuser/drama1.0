# 03 短剧

## 1. 业务目标、角色与入口

短剧模块向游客和注册用户提供内容发现、剧集播放、付费解锁、收藏及观看历史，是1.0的内容主链路。

用户端入口：

- `/home`、`/recommend`、`/search`
- `/videos/detail/:id`、`/videos/play/:id/:episodeId`
- `/favorites`、`/history`

管理端负责短剧、分组、剧集、语言、区域、上下架、封面、字幕、价格和推荐位。内容运营为主要角色；用户、游客、审核账号及系统转码/播放地址任务为其他角色。

## 2. 核心对象

| 对象 | 关键字段 | 说明 |
| --- | --- | --- |
| `Playlet` | 多语言标题/简介/封面、区域、排序、总集数、免费集数、单集价、平台可见性、状态 | 短剧主数据 |
| `PlayletGroup` | 分组、语言、位置、排序、状态 | 首页/推荐聚合 |
| `PlayletEpisode` | 集序、价格、视频ID、时长、字幕、状态 | 可播放内容 |
| `PlayletEpisodeLedger` | 用户、剧集、订单/解锁信息 | 单集购买事实 |
| 收藏记录 | 用户、短剧、状态 | 收藏/取消收藏 |
| 观看记录 | 用户、短剧、剧集、进度、更新时间 | 历史和续播 |
| 广告解锁记录 | 用户、广告、完成时间 | 短时播放鉴权条件 |

## 3. 内容目录与搜索

### 3.1 现状

1. 列表按启用状态、请求语言、区域和客户端平台过滤。
2. 支持普通分组、首页分组、批量分组、更多列表和关键词搜索。
3. 默认语言路径包含印尼语 `ind`；模型同时保存英文/印尼文标题、简介、封面和字幕。
4. iOS、Android、H5有独立可见字段；审核版本可进入特殊“电影票/审核运行”分支。
5. 推荐、播放量和收藏量包含初始化值与放大公式，不完全等于真实用户事件。

### 3.2 目标1.0规则

- 服务端根据明确的 `language`、`region`、`platform` 和应用版本返回内容，缺失时使用已文档化默认值。
- 搜索仅检索当前用户可见且已上架内容；分页排序必须稳定。
- 对缺少目标语言的字段按“目标语言 → 默认语言 → 空值占位”回落，并返回实际语言。
- 内容下架立即阻止新播放鉴权和新购买；历史订单、收藏、观看记录仍可审计。
- “展示热度”与“真实播放/收藏数”使用不同字段及文案，真实统计不能使用放大数。

## 4. 剧集列表与解锁状态

剧集逐项计算是否可播放。当前主要解锁条件如下：

1. 剧集位于短剧免费集范围或剧集价格为零；
2. 用户存在有效的一次性VIP权益；
3. 用户已购买该剧集；
4. 用户为审核账号；
5. 特定审核版本拥有兼容电影票；
6. 用户完成广告观看并满足广告解锁时效。

**目标1.0：**保留免费、一次性VIP、单集购买和明确配置的广告解锁。审核专用条件仅在受控审核环境生效，不作为普通用户规则。自动续订VIP不产生新权益，但已付费且仍有效的 `UserPlan` 继续解锁至到期。

## 5. 播放鉴权主流程

1. 客户端提交短剧ID、剧集ID和必要的应用环境信息。
2. 服务端校验短剧、剧集存在且关联正确，二者均可用且对当前平台/区域可见。
3. 对付费剧集按第4节条件重新判定，不信任列表页的 `unlocked`。
4. 鉴权成功后创建或更新观看记录，保存当前剧集/时间进度。
5. 服务端向视频供应商获取短有效期播放凭证并返回字幕信息。
6. 记录真实播放事件并更新缓存；失败不应计入已播放。

### 5.1 广告解锁差异

- `GetPlayletVideoAuth` 路径只接受最近约一分钟内完成的广告记录。
- `ListPlayletEpisode` 的解锁计算存在接受任意历史完成记录的路径。
- 老的 `GetPlayletVideo` 还有另一套鉴权分支。

这会造成列表显示可播但实际鉴权失败。该差异已由代码路径确认，目标1.0需收敛为一个服务端授权函数，并明确广告权益是“解锁一集一次”“在 N 分钟内可播”还是“永久解锁”。

## 6. 单集购买与一次性VIP解锁

### 6.1 单集购买

1. 非有效VIP用户选择付费剧集，创建 `PRODUCT_TYPE_EPISODES` 订单。
2. 服务端以剧集价格重算金额，数量必须为1。
3. 支持优先消费消费币，不足时按规则混合扣消费币与通用币。
4. 事务内扣余额、写各资产流水、完成订单并创建剧集购买事实。
5. 仅通用币支付部分参与直推/间推剧集返佣；消费币部分不返佣。
6. 返佣可先冻结，按配置天数解冻；订单退款/撤销需同步作废未解冻返佣。

### 6.2 一次性VIP

一次性VIP卡的购买、激活/排队和到期见 [12-payment-withdrawal.md](12-payment-withdrawal.md)。播放侧只读取有效权益：

- `VALIDATED` 且当前时间在有效期内时解锁付费剧集；
- 排队权益到开始时间后才能生效；
- 过期、退款或转出状态不得解锁；
- 已支付的历史自动续订权益只履约至现有到期日，不触发下一次续费。

## 7. 收藏、历史与播放量

- 收藏采用新增/更新状态，列表仅返回当前用户有效收藏且内容可展示的短剧。
- 播放鉴权成功时更新观看记录；历史列表用于续播和最近观看。
- 当前展示收藏数约为 `InitCollects × 100 + 真实收藏 × 5`；展示播放数包含 `InitViews × 10000`、数据库播放、Redis播放及放大系数。
- **目标1.0：**运营热度可保留为排序分，但页面统计须标为热度值；财务、内容结算和运营报表只能用真实事件。

## 8. 状态、异常与边界

```text
短剧/剧集草稿或下架
  └─ 不可搜索、不可新购、不可获取新播放凭证
短剧/剧集上架
  ├─ 免费或有权益：可播放
  └─ 无权益：引导单集购买或一次性VIP
订单完成
  └─ 永久记录单集解锁（退款后按规则撤销）
```

异常规则：

- 请求剧集不属于短剧：返回参数错误，不泄露视频ID。
- 视频供应商失败：不更新成功播放计数，保留可观测错误并允许重试。
- 播放凭证过期：客户端重新鉴权；不能缓存长期凭证。
- 多端并发更新进度：以较新更新时间为准，避免较旧进度覆盖。
- 单集重复购买：返回已有权益，不重复扣款。
- 退款后是否保留已看历史可由合规决定，但不再授权新播放。

## 10. 耦合与排除项

- 付费解锁依赖钱包、订单和一次性VIP权益。
- 弹幕依赖短剧/剧集及播放时间，见 [02-barrage.md](02-barrage.md)。
- 短剧支持使用同一短剧主数据但不等于购买剧集，见 [04-playlet-support.md](04-playlet-support.md)。
- 版权包、二创、活动电影票和活动素材不属于目标1.0；不能因其与短剧共用模型而误删核心播放能力。

## 11. 问题、疑问与建议

| 级别 | 类型 | 内容 |
| --- | --- | --- |
| P1 | 已确认 | 剧集列表与播放鉴权对广告完成时效判断不一致 |
| P1 | 已确认 | 播放/收藏展示数含放大公式，未与真实数据清晰区分 |
| P1 | 需验证 | 新旧播放鉴权函数并存，调用入口与安全校验可能不一致 |
| P1 | 待确认 | 广告完成后解锁范围与有效期，以及是否允许重复观看 |
| P1 | 待确认 | 一次性VIP是解锁全部付费剧集还是受地区/内容例外限制 |
| P2 | 建议 | 收敛为单一 `AuthorizeEpisode` 领域函数，所有列表和播放调用同一规则 |
| P2 | 建议 | 建立内容发布版本和规则快照，支持定时上下架及回滚 |

## 12. 验收场景

1. 不同语言、区域、平台和版本只看到允许内容，缺失翻译按规则回落。
2. 游客可播免费集但不能播付费集；购买单集或有效一次性VIP后可播。
3. 列表解锁状态与最终播放鉴权完全一致，广告权益在边界秒不产生歧义。
4. 并发重复购买同一集只扣款一次；消费币与通用币混合扣款和返佣金额正确。
5. 下架短剧不可搜索和新鉴权，历史订单、收藏、观看记录仍可审计。
6. 展示热度与真实播放指标分字段，真实报表不包含初始化/放大值。
7. 自动续订关闭后，一次性VIP和已付费存量权益仍按到期时间正常解锁。
